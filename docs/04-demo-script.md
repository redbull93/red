# Two-minute demo script — StandUp Agent

Target **110–120 seconds**. Film Slack/Discord first. Control plane last.

---

## 0:00–0:12 — The place

**On screen:** Slack or Discord team channel (`#standup`).

**Say:**
> This is where the team already stands up. StandUp Agent lives here — not
> in a new app.

---

## 0:12–0:35 — The signal only this place has

**On screen:** three DM replies (or the fixture signal feed).

**Say:**
> Eugene is blocked on Brian. Brian finished the API but never closed the
> loop. Amina is fine. A chatbot only sees this if someone pastes it.
> Slack already has it.

---

## 0:35–0:55 — The loop

**On screen:** agent plans → tool → **summary receipt in the channel**.

**Say:**
> StandUp connects the two and posts back here: Brian should send Eugene
> the API docs.

---

## 0:55–1:20 — Failure and control

**On screen:** fail → retry → Approve/Stop (HITL before @-mention).

**Say:**
> If the suggested ping is wrong, we stop it in one tap. The job retries.
> The human stays in charge.

---

## 1:20–1:40 — Theater, two breaths

**On screen:** Vengeance mission control — traces, jobs, receipts.

**Say:**
> This screen is mission control. The home is still Slack.

---

## 1:40–2:00 — Wrapper test

**On screen:** channel receipt. Hold.

**Say:**
> Pull this into a standalone chatbox and the morning ritual dies. The
> value is the place.

End. No roadmap.
