# Demo narration prompt

Use this to draft the two-minute voiceover **after** the loop works.
It is not a product brief.

## Inputs

- Environment name and kind
- Human you filmed
- Signal that appeared
- Tool that fired
- Receipt that landed
- Failure you showed
- How they stopped you

## Instructions for the writer model

Write a 160–180 word voiceover in present tense. No stack names unless
they appear on screen. No "we leveraged." Open on the place. Close on
the wrapper test: why this dies in a standalone chatbox. Three short
paragraphs max.

## Rubric the narration must serve

- Core: a finished loop in the environment
- Innovation: place-only context, spoken once
- Execution: fail, retry, stop — one sentence
- Usefulness: a named human, a named outcome
